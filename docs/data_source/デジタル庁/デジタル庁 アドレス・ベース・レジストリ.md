# デジタル庁 アドレス・ベース・レジストリ

> 都道府県・市区町村・町字の名前と識別子、代表点を配布する住所の基礎データ。住所の正規化や地域統計の結合に使えます。

## 概要・内容

デジタル庁が整備する住所・所在地の基礎データです。都道府県、市区町村、町字の名前・コードと代表点を扱います。住所文字列の正規化、ジオコーディングの基礎、地域別の集計に向いています。

## 取り出し方

[データダウンロードサイト](https://dataset.address-br.digital.go.jp/) で種類を選べます。町字の座標は都道府県ごとのZIPです。今回、東京都の座標ファイルの先頭1,024バイトを要求し、HTTP 206を確認しました。CSVの特定の住所だけを取得できる意味ではありません。

```sh
curl -fL 'https://data.address-br.digital.go.jp/mt_town_pos/pref/mt_town_pos_pref13.csv.zip' -o mt_town_pos_pref13.csv.zip
unzip -l mt_town_pos_pref13.csv.zip
```

## ライセンスと帰属表示

[ABR利用規約](https://www.digital.go.jp/policies/base_registry_address_tos) は、特記のないコンテンツにPDL1.0を適用しています。出典と利用日を記載し、加工した場合は加工した旨と主体も記載します。個別に異なる権利表記がある場合はその条件を確認してください。

## 気をつけること

- 代表点と境界は別です。町字の面が必要なら [[e-Stat 国勢調査 小地域境界]] を使います。
- `lg_code`、`machiaza_id` などは文字列として読み、先頭のゼロを保持します。
- 名前と座標で更新時点が異なり、すべての町字に座標があるわけではありません。結合できない行を数えて確認します。
- 町字より細かい街区・住居番号・地番の整備状況は、公式のお知らせで確認してください。
