# 警察庁 交通事故統計オープンデータ

> 人身事故の発生日時・位置・道路条件・当事者・死傷者数などを収録する年別CSV。事故の分布や道路安全の分析に使えます。

## 概要・内容

警察庁が公開する人身事故の記録です。事故1件の基本情報を持つ本票、当事者C以降の補充票、高速道路事故の追加情報を持つ高速票が年ごとに配布されます。事故の空間分布、時刻・天候との関係、道路安全対策の基礎分析に使えます。

## 取り出し方・データ処理コマンド

[公式の入口](https://www.npa.go.jp/publications/statistics/koutsuu/opendata/index_opendata.html) で対象年の定義書・コード表も取得してください。今回、2025年本票のRange要求にHTTP 206、全体サイズ61,424,195バイトを確認しました。年と票種を選ぶ `split` で、選んだCSV内は全体読込です。

```sh
curl -fL 'https://www.npa.go.jp/publications/statistics/koutsuu/opendata/2025/honhyo_2025.csv' -o honhyo_2025.csv
```

## ライセンスと帰属表示

[警察庁の利用規約](https://www.npa.go.jp/rules/index.html) は、特記のないコンテンツにPDL1.0に準拠した条件を適用しています。警察庁ウェブサイトと対象URLを出典として記載し、加工した場合はその旨も記載します。第三者の権利表示がある部分は別途確認します。

## 気をつけること

- CSVはShift_JIS系です。地域・警察署・票番号のコードは文字列で読みます。
- 緯度経度は度分秒を連結した値で、小数度ではありません。定義書どおりに変換します。ゼロ座標や範囲外の座標も検査します。
- 都道府県コードは警察の区分で、JIS都道府県コードとは異なります。
- 年によって列構成が変わります。複数年を結合するときは列名と定義を照合します。
- 公開された人身事故の記録であり、交通量や物損事故全体を表すものではありません。
