# 国土数値情報 鉄道データ N02

> 全国の旅客鉄道・軌道の路線と駅を収録する国土数値情報。駅へのアクセスや沿線人口、交通ネットワークの分析に使えます。

## 概要・内容

国土交通省の国土数値情報N02です。鉄道区間と駅の2層があり、路線名、運営会社、駅名、駅コードなどを持ちます。沿線の人口集計、駅への近さ、交通施設の分布を調べる用途に向いています。

## 取り出し方・データ処理コマンド

[2025年度版の配布ページ](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html) から全国のZIPを取得します。今回、先頭1,024バイトの要求にHTTP 206、全体サイズ14,903,774バイトを確認しました。配布単位は全国一括なので `whole` です。

```sh
curl -fL 'https://nlftp.mlit.go.jp/ksj/gml/data/N02/N02-25/N02-25_GML.zip' -o N02-25_GML.zip
unzip -l N02-25_GML.zip
```

ZIP内のUTF-8版GeoJSONを選べば文字コードの扱いが簡単です。内部のフォルダ構成は年度によって異なるため、一覧を見てファイルを選びます。

## ライセンスと帰属表示

2025年度版を対象に、配布ページのオープンデータ条件と [国土数値情報の利用規約](https://nlftp.mlit.go.jp/ksj/other/agreement.html) に従います。出典として国土交通省「国土数値情報（鉄道データ）」と配布URLを記載し、加工した場合はその旨も記載します。過去年度は利用条件や測量法の注記が異なるため、このカードの条件をそのまま当てはめないでください。

## 気をつけること

- 駅は点ではなく、路線の一部を表す線です。代表点に変換する場合はその方法を記録します。
- 路線形状だけから乗換・運行系統・所要時間は分かりません。経路探索には接続関係を整える必要があります。
- GeoJSONとShapefile、異なる文字コード版を重複して読み込まないようにします。
- [[e-Stat 国勢調査 小地域境界]] と重ねると沿線人口の分析に使えます。
