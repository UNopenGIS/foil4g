# SmartMaps Rwanda 10m 地形データ

> **UN Smart Maps**により提供されるルワンダの10m解像度地形タイルデータです。ルワンダの水・衛生公社と国土局のデータから作成されています。

## 説明

ルワンダの10m解像度デジタル標高モデル（DEM）から作成された地形タイル。水資源管理、土地利用計画、災害対策などの用途に活用できます。
